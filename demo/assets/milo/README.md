## 关于"抠白底"

`milo.png` 与 `milo-waving.png` 的外圈是纯白（实测 100% / 92.4%），直接使用会
在彩色卡片上露出**白色方块**。这两张用泛洪算法抠成透明（分别去掉 36.3% / 39.1%
画面），让奶龙真正"趴"在卡上。

其余 7 张自带场景底，按参考文档 §二 的说法"圆形裁切后趴出来"使用，保持原样。

> 抠图算法与上一版（v2 的 5 张素材）是同一套，当时已验证有效。

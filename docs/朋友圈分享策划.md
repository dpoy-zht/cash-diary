# 奶蛙记账 · 朋友圈分享策划

> 生成日期：2026-10-10 · 对应版本 v2.3.20（code 244）
> 配图已实拍自 H5 构建产物（真实渲染，非设计稿），存于 `dist/_shots/`

---

## 一、App 定位

**一句话**：一只黄色小胖龙盯着你花钱的**离线记账本**，数据只存在你自己手机里。

三个关键点（这决定了怎么写文案）：

| 维度 | 事实 | 对文案的含义 |
|---|---|---|
| **隐私** | 没有服务器，**不联网、不上传、不分析** | 这是最强差异点，必须说透——「没有服务器想分析也分析不了」 |
| **完整度** | 记账 / 流水 / 统计 / 预算 / 备份**全部自己写**，无广告无内购 | 不是「小工具」，是能天天用的正经 App |
| **性格** | IP 形象 + 按压动效 + 音效，奶蛙会Sad 脸看你超支 | 语气可以皮，但别油腻 |

> ⚠️ 一条硬约束：**仅 Android**，且分发走 GitHub Releases（非应用商店）。
> 文案里不要写「上架了」「应用商店下载」，那会直接翻车。

## 二、核心功能（挑能讲故事的讲）

按「朋友圈读者会不会关心」排序，不按功能表顺序：

| 优先级 | 功能 | 一句话卖点 |
|---|---|---|
| ⭐⭐⭐ | **两级分类** | 12 个一级 / 49 个分类，早餐午餐奶茶各归各位，不用全挤在「餐饮」里 |
| ⭐⭐⭐ | **统计下钻** | 圆环图点一级看二级，钱到底花在哪一目了然 |
| ⭐⭐⭐ | **超支提醒** | 花超了奶蛙露 Sad 脸看你，App 还在后台发系统通知 |
| ⭐⭐ | **计算器式记账** | 能连续运算，`10-10` 直接出结果，不用反复清空重输 |
| ⭐⭐ | **多账本** | 「日常账本」管生活，「小金库」管私房钱 |
| ⭐⭐ | **备份/恢复** | JSON 导出，卸载重装不丢账；还能从剪贴板恢复 |
| ⭐⭐ | **固定支出** | 房租话费每月自动记账，到期提醒 |
| ⭐ | 趋势图 / 流水搜索 / 标签 / 体检页 / 连续记账等级 | 凑数量用，文案里一句话带过 |

## 三、目标用户

**画像一（主力，约占一半）**：想认真记账但被记账 App 劝退的人——试过几个，要么要注册登录，要么广告弹窗，要么数据不敢放在别人服务器上。

**画像二**：已经在用但数据被绑架的人。手机丢了 / 换机 / App 被下架 → 数据没了。

**画像三**：被「记账坚持不下来」打败过的人。这只 App 的 IP、动效、音效就是给这批人的。

**共同点**：**在意数据归属 + 讨厌被分析**。所以文案主打「离线 + 无账号 + 不联网」比主打「功能多」有效得多。

## 四、三条文案（不同风格）

### 风格 A · 讲道理型（最稳，适合技术圈 / 同事）

> 自己写了个记账 App，**奶蛙记账**。
>
> 做它的起因很实在：我想记的账不想传到别人服务器上。市面上那些要么要注册、要么弹广告，看了源码才发现还有一层——你记的每一笔都成了别人的数据资产。
>
> 所以它**没有服务器**。不联网、不上传、不分析。飞行模式里照样能记。
>
> 记账本身也没糊弄：两级分类（早餐 / 午餐 / 奶茶各归各位）、统计圆环能点开看子类、超支了会弹通知提醒、房租话费每月自动记、备份导出成 JSON，换手机不丢账。
>
> Android 直接装：<https://github.com/dpoy-zht/cash-diary/releases/latest>
>
> 源码在下面，MIT，随便看随便抄。

**为什么这样写**：把「没有服务器」放在最前面——这是唯一别人抄不走也模仿不来的点。技术圈的人看到「不联网」会比看到「49 个分类」更在意。

---

### 风格 B · 讲痛点型（最容易共鸣，适合朋友圈主力）

> 记账这件事我坚持了三年，App 换了五个。
>
> 共同问题只有一个：**我的账本在别人手里。**
>
> 去年手机进水，换了个手机，两个月的账没了 —— 从此我再不敢把账本交给任何需要登录的 App。
>
> 所以自己写了一个：**奶蛙记账**。
>
> 没有服务器。**不联网、不注册、不上传** —— 不是「我们不收集你的数据」，是压根没有能收集的地方。
>
> 功能反而没偷懒：早餐午餐奶茶分得清清楚楚、圆环图点开能看子类、花超了它会瞪我、房租每月自动记、账本能导出成一个 json 文件揣兜里。
>
> Android 可装，链接放评论了。

**为什么这样写**：先立一个具体痛点（三月/五个App/手机进水），再给解法。朋友圈里第一人称 + 具体细节比形容词有效得多。链接放评论可以避免「看起来像广告」。

---

### 风格 C · 皮一下型（最容易点赞，适合想让朋友试用）

> 奶蛙盯着我花钱的第 N天。
>
> 它现在会说：「你这个月超了¥426。」
>
> 然后露一张 Sad 脸，比我妈的眼神还有杀伤力。🙃
>
> 「奶蛙记账」，Android 可装：
> 没有服务器、不联网、不注册 —— 我不是不想传，是**压根没地方传**。
>
> 记账这事它替我干了：早餐午餐奶茶各记各的、房租话费每月自动入账、我记一笔它给我算结果（能连续运算）。
>
> 链接放评论⬇️

**为什么这样写**：朋友圈要的是「会心一笑」。用 IP 的性格当钩子，而不是罗列功能。超支那句具体数字比「支持预算」有画面感。

---

### 挑哪条？

| 场景 | 建议 |
|---|---|
| 发在**技术/程序员朋友圈**，同行多 | A（讲道理，顺便把GitHub 露出来） |
| 发在**日常朋友圈**，想让人下载 | B（痛点共鸣，最可能真有人装） |
| 想让朋友圈**互动起来**（点赞、评论） | C（最容易搭话，评论区可以接「要不要发你」） |

已实拍 6 张（`dist/_shots/`），均为真实渲染。**朋友圈九宫格建议 6 张**，不要更多。

| 顺序 | 文件 | 突出什么 | 为什么放这个位置 |
|---|---|---|---|
| **1** | `home-0.png` | **首页主界面**：余额卡 + 奶蛙 IP + 流水列表 | 第一张决定点不点开。余额卡有真实数字（已花 ¥6,261.80），IP 表情有记忆点，一眼说明「这是个正经 App」 |
| **2** | `stats-0.png` | **统计页**：圆环图 + 图例 + 近 6 个月趋势柱状图 | 全 App 视觉上最抓人的一张。证明「不是只能记账，还能分析」 |
| **3** | `add-0.png` | **记一笔**：两级分类选择器 + 计算器键盘 | 展示差异化的关键——49 个分类不是噱头，真能选。彩色图标密集，视觉上好看 |
| **4** | `budget-0.png` | **预算页**：总预算超支条 + 分类预算树 | 对应「超支提醒」这个卖点，也是最有实用感的一页 |
| **5** | `fixed-0.png` | **固定支出**：房租 / 话费自动记账配置 | 说明「它会替你干活」，这是记账 App 的核心价值 |
| **6** | `me-0.png` | **我的页**：等级 + 连续记账 8 天 + 全部功能入口 | 收尾用。一屏看完功能全貌，且有「已坚持 8 天」这类真实使用痕迹 |

**排列逻辑**：主界面（这是什么）→ 分析（能干什么）→ 录入（怎么用）→ 管钱（省心）→ 自动化（更省心）→ 全貌（随便看）。

**如果只放 3 张**：`home` → `stats` → `add`（对应「是什么 / 能干什么 / 怎么用」）。

**⚠️ 配图纪律**：
- 不要放 `report` / `health` / `tag` / `category` 页——信息密度低，看不出价值，浪费格子。
- 截图里**必须**有真实数字（已灌入当月+上月数据），空数据或全0 的图说服力为零。
- 别加美颜边框/大滤镜。UI 本身配色够暖，加滤镜会和 App 实际观感不符。

## 六、配文标签

朋友圈标签有两种放法，**二选一，别都堆**：

**方案 1：正文末尾（推荐）**
```
#独立开发 #安卓应用 #记账App #离线优先 #开源项目
```
5 个以内，多了像刷屏。

**方案 2：评论区补充**
正文末尾只放 `#独立开发`，评论区补：
```
#记账App #安卓 #开源 #GitHub #隐私优先 #小众工具
```

**标签选择原则**：优先选**能让同类人找到你**的标签（`#独立开发` `#开源项目` `#安卓应用`），而不是流量大的泛标签（`#APP推荐` `#手机软件`）—— 后者带来的不是目标用户。

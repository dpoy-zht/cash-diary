## 1. 项目目标与技术栈

### 1.1 目标与定位

一个**不需要服务器**的记账工具。数据只存在用户手机本地，不联网、不注册、不上传、不分析。

- **核心卖点**：没有服务器 → 用户对「我的账本在别人手里」这件事没有顾虑。
- **性格**：IP 形象「奶蛙」（黄色小胖龙）+ 按压动效+ 音效 + 超支时露 Sad 脸。
- **不追求**：功能堆量。README 明确「核心功能早已定版，此后以数据修复与兼容性维护为主」。

### 1.2 技术栈（实测自 `package.json`）

| Vue | `3.4.21`，全部 SFC 用 `<script setup>` |

## 2. 目录结构与模块职责

```
src/
├── pages/            11 个页面（见 §3.1）
├── components/       15 个组件，easycom 自动注册，无需 import
├── services/         11 个业务层（业务规则、编排）
├── db/               数据层：schema /双适配器 / repository
│   ├── schema.js         ★迁移事实源（MIGRATIONS v1–v7）
│   ├── sqlite.js         App 端事实源（plus.sqlite）
│   ├── memory.js         H5 + vitest 事实源（localStorage）
│   ├── index.js          适配器选择（按运行平台）
│   ├── sql-value.js      值转义（plus.sqlite 无参数绑定）
│   ├── tx-search-sql.js  ★动态 SQL 唯一出口（纯函数）
│   └── repository/       7 个仓储，每个方法两适配器签名严格对齐
├── stores/           7 个 Pinia store（account/budget/category/fixed/meta/tag/tx）
├── utils/            22 个纯函数工具（money/date/stats/budget/…）
├── static/           素材（milo 原图包 + meme 自制包 + sfx 音效）
├── manifest.json     ★版本号真源
├── pages.json        11 页全部 navigationStyle: custom
└── App.vue           动效底座 + 全局 hover 类
```

### 2.1 分层与调用方向

```
页面(.vue) → store → service → repository → 适配器(sqlite/memory)
                ↘ utils(纯函数，随时可测)
```
- **service 层不认识 HTTP/UI**，只管业务规则与编排 → 可直接单测。
- **repository 层是唯一持有「某张表怎么读写」的地方**。
- 样式计算逻辑**必须落成 `.js`** 才有测试价值（vitest 跑不了 scoped 样式）——先例：`db/tx-search-sql.js`、`mascot-deco/spec.js`。

### 2.2 数据表（7 张）

| 表 | 用途 | 关键列 |
|---|---|---|
| `category` | 分类（**两级**，`parent_id` NULL=一级） | `parent_id` / `icon` |
| `transaction_record` | 流水（**软删** `deleted_at`） | `occurred_at` / `amount_cents` / `account_id` |
| `account` | 账本（多账本） | `name` |
| `budget` | 预算（`category_id` NULL=总预算） | `limit_cents` / `account_id` |
| `fixed_expense` | 固定支出（月度自动补记） | `category_id` / `day_of_month` / `last_posted_ym` |
| `tag` | 标签 | — |
| `transaction_tag` | 流水↔标签多对多 | — |

⚠️ **列名易错**（实测确认）：时间是 `occurred_at`（**不是** `ts`）、金额是 `amount_cents`、预算是 `limit_cents`（**不是** `amount_cents`）。

### 3.2 核心机制（均已实现且有测试）

- **两级分类**：`12 个一级 + 37 个二级 = 49 个支出分类`，另8 个收入分类保持一级平铺。
  唯一事实源 = `services/category.js: EXPENSE_TREE`（种子与老库迁移**共用一份**）。
  老库迁移 `migrateCategoryTree()` **幂等**，判据是「库里还存在老叶子名的平铺分类」，**不存迁移标记**。
- **多账本**：`account` 表 + `account_id`（迁移 v3–v5）。**过滤统一在 `stores/tx.js: currentAccount()` 注入**
  （实测：`loadMonth` / `loadStatsPeriod` / `loadReport` / `loadTrend` / `search` / `addTx` 全走它）
  → 页面不需要各自处理账号隔离，架构干净。
- **固定支出自动补记**：`postDueFixed()`，从 `last_posted_ym` 的下月起逐月补，最多回看 60 个月；
  创建时置当前月 → 从下月生效。
- **备份/恢复**：`BACKUP_VERSION = 3`，兼容读 v1/v2（缺表按空数组，老备份必须始终能恢复）。
  恢复前整包校验。读写路径**对称**（导出到公共目录，恢复也扫公共目录）。
- **热更新**：自建源 `http://121.40.24.123/update/latest.json` 优先，GitHub 兜底且**代理排第一、直连排最后**
  （实测直连会在随机位置断流）。完整性用**文件大小**校验（非 JS SHA-256，App 端过慢）。
- **超支提醒**：应用内弹窗 + 后台系统通知（`services/reminder.js`）。
- **素材双包**：`milo`（默认）/ `meme`，`ACTIVE_PACK` 一键切换。
- **动效与音效**：`App.vue` 有 `--cd-dur:180ms` + 4 个 keyframes + `prefers-reduced-motion` 兜底；
  `playSfx()` 三重保护静默失败。

## 5. 关键技术决策与约定（⚠️ 接手必读）

### 5.1 数据层三条铁律（不可违背）

1. **金额一律整数分**存储，禁止浮点。
2. **时间存毫秒时间戳**，统计按**手机本地日历月**分桶。
3. **删除一律软删除**（`deleted_at`），备份文件也必须保留该字段。

### 5.2 改数据结构的四个必改点

新增表/列必须**同时改四处**，漏一处即出问题：

| 位置 | 内容 |
|---|---|
| `db/schema.js: MIGRATIONS` | 追加迁移（**只追加**，v1…v7） |
| `db/sqlite.js: TABLE_COLS` | 列清单 |
| `db/memory.js: TABLES` | 表清单 |
| 两侧 `clearAll` | 清库逻辑 |

- 迁移条目格式：`sql` + `statements`（**一元素一语句、无尾分号**）。
- ⚠️ `tests/schema.test.js` 断言迁移版本数组**精确相等** → **加迁移必须同步改断言**，否则必挂。
- ⚠️ 两适配器方法签名必须严格一致（`tests/contract.test.js` 守护），改一处必须同步另一处。

### 5.3 App 端特有坑（浏览器测不出来）

| 坑 | 后果 | 规避 |
|---|---|---|
| **App 端逻辑层没有 DOM** | 独立 V8/JSCore，渲染层才是 WebView。`typeof CSS === 'undefined'` **恒成立** → 任何 `CSS.supports` / `document.*` 能力探测**都是假的** | **别做能力探测**，直接用特性 + CSS 兜底 |
| **无 `Intl`** | `(1800).toLocaleString('zh-CN',{minimumFractionDigits:2})` → `'1800'`（小数点消失） | 走 `money.js: groupThousands()/compactYuan()/amountSizeClass()`、`date.js: toDateStr/dateTimeLabel` |
| **`plus.io` 的 `createReader()`** | vivo/OriginOS 上**永久挂起**（既不 success 也不 error）→ 表现为「点了没反应」 | 所有 plus.io 异步调用套 `backup-file.js: withTimeout()` |
| **备份读写路径不对称** | 导出到公共目录、恢复只扫私有目录 → 「导出了却恢复不了」 | 新增功能时**检查读写路径是否对称** |
| **`plus.sqlite` insert 无 `lastInsertRowid`** | 拿不到新行 id | 插完**重读库**取 id |
| **`plus.downloader` 回调多次触发**（0→1→2） | 重复安装 | 第一次必须 `return` |
| **`plus.runtime.install` 需绝对路径** + `{force:true}` | 拒同/低版本 | 用 `entry.fullPath` |
| **`_doc/update.wgt` 必须单斜杠** | 双斜杠造出名为 `:` 的畸形目录 → install 找不到 | 路径规范化 |

⚠️ **H5 有完整 ICU、也有 DOM** → 这两类 bug 在浏览器里**永远测不出来**，只有真机能暴露。

### 5.4 UI 约定

- **对比度 ≥4.5:1**；`--cd-ink-3`(1.81:1) **不承载正文**，只做装饰。正文用 `--cd-ink-2`(4.53:1)。
- **记账入口只有 Tab 中央「+」**；页面 `padding-bottom:90px` 让位 Tab 栏，别删。
- 组件 CSS **独立文件** `pages/x/x.css`，**不进 `app.css`**（只有全局类在）。
- `hover-class` 必须引 `App.vue` 全局类：`.pressable` / `.pressable-hover` / `.rise-in`
  （模板里写死字符串，scoped `:deep` 命中不了）。
- `<text>` 进横向 flex 要显式 `display:block`；间距用 CSS margin，**别靠模板空白**（会被编译吃掉）。
- chip 要 `flex:none; white-space:nowrap`（否则「早餐」被压成「早/餐」）。
- **大号金额不能等分两列 + 大 padding**：窄屏 360dp + 系统大字体必被ellipsis 截断。
  `compactYuan`（≥9 字符→「¥1.2万」）+ `amountSizeClass`（字号分档）**两者必须一起用**
  —— 只降字号挡不住系统字体缩放。**定宽是死值、系统字体是变值。**
- `components/X/X.vue` 靠 easycom 注册为 `<X-kebab>`，**不写 import**。
- 静态资源 `lazy:false` 是**刻意**的。
- ⚠️ **批量正则改 `.vue` 前必须先切段**（template/script/style/tail），只在 style 段操作，否则 CSS 会插进 `<script>` 炸编译。

### 5.5 素材体系

- **`src/static/milo/` 原图一个字节都不能改**，`tests/asset-packs.test.js` 有 18 条断言守护（含 blob 哈希）。
- `icon` 存参考包 key，取色**按 icon 不按名字**。合法 key 只有 `palette.js: CATEGORY_ICONS` 里那些
  （如 `edu`/`comm`/`social`，**没有** `book`/`phone`）→ **写错会让 key 名直接漏到 UI 上**。
- ⚠️ 基础形象是 `milo.webp`（**无连字符**），其余是 `milo-<表情>.webp`。别「顺手统一命名」。
- 占位框的空间规格**只认** `asset-slots.js` 登记表，别挂页面的 `img-class`。
- `docs/asset-checklist.md` **由代码生成**：改登记表后必须跑 `python scripts/gen-asset-checklist.py`（测试断言文档与代码一致）。
- ⚠️ **版权**：原图奶蛙角色为网络流传素材，**仅限个人自用**；`meme` 包为自制。公开分发/上架前须评估授权风险。

- **版本号三处同步**：`src/manifest.json`（真源）、`package.json`、`README.md`。
- ⚠️ `git status` 显示 ` M xxx` 但 `git diff` **为空** = 纯 CRLF 差异，`git checkout --` 即可，别去「修」。

### 6.1 发版流程（顺序错了白打一轮云打包）

```bash
# 1. 升版本（三处同步）
#    src/manifest.json versionName/versionCode + package.json + README

# 2. 门禁 + 构建
```

### 6.2 发版铁律（实测踩过的坑）

| 坑 | 说明 |
|---|---|
| ⚠️ `release.js` **本机走不通** | 它在 Node 里 `spawnSync` 托管 python → 被沙箱拦成 `EBUSY`。改手工跑 `gen-latest-json.py` + `push-update.js`（不 spawn 任何子进程） |
| ⚠️ `--config` **必须绝对路径** | 相对路径报「参数错误」且 **exit 0 假成功** |
| ⚠️ **排队时段决定速度** | 22:40 提交 → 队列 94 位、15 分钟未进打包；08:07 → **1 分 13 秒** |
| ⚠️ **轮询进程随会话回收** | 云端任务照跑完成但 APK 不落本地 → 重跑一次 `pack` 即可 |
| ⚠️ Release body 必须含 **`wgt-sha256: <64位hex>`** | 正则 `/wgt[-_]sha256[:：=\s]+([0-9a-fA-F]{64})/`。写成 `wgt SHA-256：` 会让校验**静默跳过** |
| ⚠️ 改说明必须**先摘出再放回**校验行 | 否则热更校验被跳过 |
| ⚠️ 重发同 tag 必须先删线上资产 | GitHub 不允许同名共存（直接 POST 返 422）；脚本已自动处理 |
| ⚠️ 热更「先有鸡先有蛋」死锁 | 修复代码在 wgt 里 → **必须手动装一次 APK** 才生效 |
| ⚠️ 包内校验**搜业务字面量，别搜函数名** | 压缩器会改名（`selectRestoreNames` 在包里已不存在）。中文要同时试 `\uXXXX` |

### 7.2 验证盲区

- **H5 掩盖 App 端 bug**：无 `Intl`、无 DOM 这两类问题浏览器永远测不出。
- **真机只能可靠验首页**：HyperOS 封锁 `input tap/swipe`/`sendevent`/`pm grant` → 无法自动点击；
  且**真机切页也做不到**（探针 `uni.reLaunch` 缺页面上下文静默失败）。
  → 其他页面用 H5 截图验，**多页交互需用户手动点 + AI 连拍 `screencap`**。
- **迁移类改动必须用「pull 库对拍」**：force-stop → pull `doc/cash-diary.db`（**连 `-journal` 一起**）→
  装新版冷启动 → 再 pull → `sqlite3.connect('file:x.db?mode=ro', uri=True)` 逐表 diff。
  金额对拍**必须区分软删**（未删 + 已删 = 总额）。

### 7.3 环境与工具

- **清 `dist/build/{h5,app}` 会撞安全策略**（单次删 ≥50 文件被拦）→ 先 `mv` 到暂存区。
- **Git Bash 无 `pkill`**：`netstat -ano | grep :PORT` → `taskkill //PID //F`。**每次换端口**（TIME_WAIT）。
- **服务器不能用管道启动**：`python -m http.server | head` 会导致 curl 返 `000`；要用 `exec` 或后台任务。
- **`git push` 在本机会卡死**：PortableGit 的 `credential.helper=helper-selector` 非交互永久挂起。
  全局已修为 `manager`；换机器需 `git config --global credential.helper ""` 再 `--add credential.helper manager`。

## 四、后续迭代预留情况（结论：扩展性好）

| 机制 | 评价 |
|---|---|
| **分层架构** | pages → stores(Pinia) → services → repository → adapters，职责清晰，页面不感知多账本 |
| **数据库版本化** | `MIGRATIONS`（v1..v6）只追加不修改，新表 = 迁移 + 两适配器表清单 + clearAll 三处，**有契约测试守门**（方法集一致 + dumpAll 键集合一致） |
| **备份版本化** | `BACKUP_VERSION=3`，**v1/v2 老备份永远可恢复**（缺表按空数组），已单测锁定 |
| **SQL 安全** | 动态 SQL 唯一入口 `tx-search-sql.js` 纯函数，动态值过 `sqlValue()`，逐字断言测试 |
| **设计令牌** | 全部色值收敛 `--cd-*`，有守门测试禁硬编码 —— **这是将来做深色模式的现成基础**（补一组暗色令牌变量即可，页面不用改） |
| **组件机制** | uni-app easycom 自动注册，新增组件零配置 |
| **纯函数偏好** | 统计/口径/日期/金额全部在 utils 纯函数，页面只排版 —— 改口径不会漏页面 |
| **明确的预留口** | `stopReminders`（重置用）、`openReleasePage`（整包回退）、`TREND_MONTHS` 等常量集中 |

**结论：模块化程度高，加功能有清晰的落点，不需要重构。**

## 五、风险点（按优先级）

| # | 风险 | 级别 | 说明与建议 |
|---|---|---|---|
| 1 | **素材 IP 属性** | **高**（仅当对外分发） | 当前形象是抖音 meme 角色（tungtungtungmimi 等），仅限个人自用；公开分发/上架前必须换授权素材或换回原创形象（死组件 mascot 是现成的原创备胎） |
| 2 | **热更下载在国内不稳定** | 中 | 真机实测：`api.github.com` 通，但资产域 `objects.githubusercontent.com` 下载 40s 超时。回退逻辑正常，但用户"点更新"可能失败需重试。建议：wgt 同步一份到国内可达的镜像（Gitee Releases / 自有服务器），App 端依次尝试 |
| 3 | **深色模式缺失** | 中 | P2 承诺未做；奶油色系在暗环境下刺眼。令牌已集中，属"补一组变量"的工作量 |
| 4 | **桌面图标不入库** | 中 | `unpackage/res/icons/` 被 manifest 引用但整体 gitignore —— 换机器克隆后云打包缺图标。建议挪进 git 跟踪目录并同步改 manifest |
| 5 | **皮肤空占位入口** | 低 | 点得到没功能；定版前隐藏或实现 |
| 6 | **`resetAll()` 未调 `stopReminders()`** | 低 | `stopReminders` 注释说"重置数据用"但重置流程没接。影响小（refresh 会自愈），属文档意图与实现不一致 |
| 7 | **死代码清单** | 低 | mascot.vue + 5 个死导出 + 假 jpg；不影响运行，清不清随意 |
| 8 | **本机 `dist/pack-config.json` 含明文证书密码** | 低 | 未入库（gitignore），但文件还在；建议决定保留（发版方便）或删除（降低暴露面） |
| 9 | `package.json` version=0.1.0 与 App 版本不同步 | 极低 | 仅包管理器标识，不影响构建；可顺手改成 2.2.3 |

## 六、结论与两种收尾方案

**结论：v2.2.3 已达到"个人使用的最终稳定版"标准；若以 PLAN.md 的完整规划为尺，还差三件事，不建议现在宣布"最终完整版"。**

已达标的部分：P0/P1 100%，日常记账所需功能全部具备且有 593 项自动化测试 + 真机热更链路验证；代码卫生与扩展性在同类个人项目里属于高水准。

**方案 A —— 就此定版（工作量半天）**
1. 隐藏「皮肤」空占位入口（或一行注释保留代码）
2. 清理 5 个死导出 + 删 `look-big-dragon.jpg`（mascot.vue 建议保留作为原创备胎）
3. 把"深色模式 / T5.4 / T5.3"正式标记为**不做**（写进设计文档决策记录）
4. 宣布 v2.2.3 为最终版，之后只做数据修复与兼容性维护

**方案 B —— 再做一批"收尾批"后定版（工作量 2~4 个批次）**
1. **深色模式**：补暗色令牌组（页面零改动的可能性大，因色值已全部走令牌）
2. **T5.4 小票图片附件**：按 `docs/batch5-design.md` 方案①实施
3. 顺手项：镜像下载源、图标入库、§五 的低风险清理
4. 完成后升 v2.3.0 定版

> 无论选哪个，**风险 1（素材授权）在对外分发前必须处理**；仅个人自用则可忽略。

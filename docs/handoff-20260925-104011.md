## 必须遵守的约束（改动前先读）

- **数据三铁律**（见 `docs/技术方案.md` §4.4）：金额一律整数「分」、时间一律毫秒时间戳、删除一律软删除。**改 UI 时不得触碰这三条**。
- **`utils/money.js` 与 `utils/date.js` 是唯一允许做金额/时间换算的地方**，页面与组件不得自行换算。
- **设计规范**见 `docs/PRD.md` §8：支出红 `#E24B4A` / 收入绿 `#12924F`（中国习惯，红支绿收）、千分位两位小数、危险操作二次确认。
- **`AGENTS.md`**：每次改动必须有 commit；必须在测试与验证全绿后才能交付。
- **架构级变更**（目录结构、分层方式）要先改 `docs/技术方案.md` 再动代码。

## 环境要点（新会话必知，避免重复踩坑）

| 事项 | 说明 |
|---|---|

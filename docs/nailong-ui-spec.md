## 2. 视觉基调：从"奶龙"里提取什么

参考对象是《奶龙》（第七印象）的**风格语言**，不是照搬角色形象。提取出四条可工程化的特征：

1. **明亮温暖的黄色为主体色**——不是糖果荧光黄，是偏奶油/蛋黄的低饱和暖黄。
2. **一切皆圆润**——圆脑袋、胖身材的造型语言，投射到界面就是"没有直角"：卡片 20–28px 圆角，标签全用胶囊。
3. **黑亮圆眼 + 两朵红晕**——这是奶龙最可识别的面部特征，成为吉祥物的核心元素。
4. **温暖治愈而非冷硬**——用暖深棕替代纯黑做文字色，阴影带暖调，遮罩不发灰。

### 关于角色形象的处理方式（重要）

吉祥物 **「小记龙」是本次原创的**，只借鉴风格特征，不复制奶龙的具体形象：

- 采用纯 CSS 几何绘制（`<view>` + `border-radius` + 渐变 + 内阴影），**不引入任何图片/SVG 资源**。
  好处是：APK 体积零增长；H5 / App / 未来小程序三端通用（小程序不支持内联 `<svg>`）。
- 只做**头像式**（仅头部），不做全身：46px 的下限尺寸下，全身造型会糊成一团，只留头部才能保持清晰。
- 与真实 IP 的差异是刻意保留的：奶龙无耳朵、有长尾巴与短爪，本吉祥物改用一撮"呆毛"区分，避免与商业 IP 形象混淆（若将来公开发布，也不存在形象侵权风险）。
- 两个表情状态：`happy`（默认，用于记一笔金额区、我的页）/ `sleep`（眯眼打盹 + 浮动 + "z"，仅用于明细空状态）。

### 3.2 为什么保留 #e24b4a / #12924f（而不是一起调暖）

这两个是**语义色**，不是装饰色：红支绿收是 PRD §8 冻结的产品规范，用户对金额方向的识别依赖它。
把它们调成暖色会削弱语义、且违反已冻结的文档。因此本次只换"氛围色"（底、容器、主色），**语义色原样保留**。

### 3.3 语义色的使用规则（本次新增的可访问性约束）

金额红绿在**白底**上的对比度是 3.94:1 / 4.00:1——达到 WCAG AA 的**大字号**门槛（≥3:1），但达不到正文字号的 4.5:1。
因此定死一条规则：

> **红 / 绿只出现在金额数字上，且金额一律 ≥19px 粗体。**

推论：
- 记一笔大金额 30px、明细条目金额 19px、月合计 19px —— 全部命中"大字号"档。
- 「支出 / 收入」这类小字标签一律用 `--cd-ink` / `--cd-ink-2`，不用红绿（分段控件的选中态改用品牌黄底 + 深棕字）。
- 唯一的红色小字场景（删除按钮）走加深档 `--cd-danger-ink`，对 `--cd-danger-lt` 为 4.90:1，满足正文 4.5:1。

### 3.4 分类图标底色

`src/utils/palette.js` 提供 8 个柔和底色，按**分类 id**（不是数组下标）循环取色：

```
#fff0be 奶黄 · #e6f6ff 天空蓝 · #ffedf0 腮红粉 · #e8f8f0 薄荷绿
#fff1e3 奶油橙 · #ede9ff 淡紫 · #e4f5f7 淡青 · #fbeaf2 淡玫
```

内置分类 id 为 1..12（8 支出 + 4 收入），8 色一循环后：**支出 8 项颜色两两不同，收入 4 项也两两不同**。
按 id 取色（而非按位置）是为了让同一分类在宫格、明细列表、编辑弹层 chip 三处颜色完全一致。

## 4. 一致性原则

### 4.1 圆角

| 令牌 | 值 | 用途 |
|---|---|---|
| `--cd-r-pill` | 999px | 标签、chip、把手 |
| `--cd-r-lg` | 28px | 卡片、弹层顶角 |
| `--cd-r-md` | 20px | 按钮、输入框、分组卡、金额卡 |
| `--cd-r-sm` | 16px | 键盘键、分段控件内块 |

规则：**界面内不出现直角**；同类元素必须用同一个令牌，不允许"这里 10px 那里 12px"。

### 4.2 字体

- **不打包字体文件**（避免 APK 体积与首屏成本），使用系统圆体栈：
  `MiSans → HarmonyOS Sans SC → PingFang SC → Noto Sans SC → system-ui`
  测试机 Xiaomi 14 Pro / HyperOS 命中 **MiSans**，本身即圆润几何无衬线，天然贴合本风格。
- 字号档位：11 / 12 / 13 / 14 / 15 / 16 / 17 / 19 / 21 / 30px。
- 字重只用 400 / 600 / 700；标题与数字一律 700，避免"胖乎乎"的圆润造型配细字重。
- **所有金额数字**加 `font-variant-numeric: tabular-nums`，保证等宽、翻转与编辑时不跳动。

### 4.3 动效

| 场景 | 表现 |
|---|---|
| 键盘按键 | 按下 `scale(0.94)` + 底色转浅黄（180ms 轻回弹曲线） |
| 分类选中 | 图标底转主黄渐变 + 金色描边环 + `scale(1.06)` |
| 分类按下 | 图标 `scale(0.92)` |
| 主按钮 | 按下 `scale(0.985)` + 透明度 0.9 |
| 编辑弹层 | 底部上滑 240ms + 遮罩淡入 200ms |
| 空状态吉祥物 | 2.8s 循环上下浮动 8% |

统一缓动 `--cd-ease: cubic-bezier(0.34, 1.35, 0.64, 1)`（略带回弹，呼应软萌）。
`App.vue` 里已加 `@media (prefers-reduced-motion: reduce)` 全局降级，尊重系统"减弱动态效果"。

## 5. 对比度实测（WCAG 2.1）

| 组合 | 比值 | 结论 |
|---|---|---|
| `--cd-ink` 对奶油底 `--cd-bg` | **10.9:1** | AA / AAA 正文通过 |
| `--cd-ink` 对白卡 | **11.5:1** | AA / AAA 正文通过 |
| `--cd-ink` 对品牌黄 `--cd-primary`（导航栏、选中态） | **8.1:1** | 通过 |
| `--cd-ink-2` 对白卡 / 奶油底 | **5.3:1 / 5.0:1** | AA 正文通过 |
| `--cd-ink` 对按钮渐变最亮端 `#ffe98f` | **9.5:1** | 通过 |
| `--cd-expense` 对白卡（19px 粗体） | **3.94:1** | AA 大字号通过 |
| `--cd-income` 对白卡（19px 粗体） | **4.00:1** | AA 大字号通过 |
| `--cd-danger-ink` 对 `--cd-danger-lt`（删除按钮） | **4.90:1** | AA 正文通过 |
| Tab 选中字 `#8a5a0f` / 未选中 `#7e6849` 对 `#fffdf7` | **5.8:1 / 5.2:1** | 通过 |
| 禁用态文字 `--cd-ink-3` 对 `--cd-cream` | 2.1:1 | 低，但 WCAG 1.4.3 明确豁免禁用控件 |

触达面积：键盘键高 50px、主按钮 50px、弹层按钮 46px，均 ≥44px（WCAG 2.5.5）。
